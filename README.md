# STAF.Selenium.Tests

This repository is a simple sample implementation demonstrating usage of the `STAF.UI.API` NuGet package.

NuGet package: https://www.nuget.org/packages/STAF.UI.API

Prerequisites
- .NET 8 SDK

Basic commands
- Restore packages: `dotnet restore`
- Build: `dotnet build`
- Run tests: `dotnet test`

Notes
- Test data files are located in the `TestData` folder.
- `nuget.config` is configured to use the official NuGet v3 feed.
