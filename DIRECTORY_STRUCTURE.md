## Maintenance & Updates

### When to Update Documentation

| Scenario | Update Files | Reason |
|----------|--------------|--------|
| **New pattern discovered** | `docs/AI_GUIDE.md` + skill file | Centralize knowledge |
| **Code generation issue** | `.cursor/cursor.rules` | Enforce consistency |
| **Platform-specific tip** | Platform file (`.github/`, `.vscode/`, `.cursor/`) | Help users with that tool |
| **New golden example** | `docs/AI_GUIDE.md` + skill file | Show best practice |
| **Workflow change** | `.cursor/cursor.rules` + `docs/AI_GUIDE.md` | Keep everyone aligned |

