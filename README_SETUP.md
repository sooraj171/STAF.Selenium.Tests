## 🚀 Getting Started (Right Now)

### For Visual Studio Users

```
1. Open Visual Studio
2. Open any test file (STAFTests/Tests/*.cs)
3. Press Ctrl+Shift+I (GitHub Copilot Chat)
4. Ask: "Create a UI test for login using ParaTests pattern"
5. Review generated code
6. Copy to your file and build/test
```

**Reference:** `.github/copilot-instructions.md`

### For VS Code Users

```
1. Open VS Code with STAF.Selenium.Tests folder
2. Open a test or page file
3. Press Ctrl+Shift+I (Copilot Chat)
4. Ask: "Create a page object using LoginPage.cs pattern
		 Reference @STAFTests/Pages/LoginPage.cs"
5. Review and integrate code
6. Run: dotnet test --filter "ClassName~YourClass"
```

**Reference:** `.vscode/README.md`

### For Cursor Users

```
1. Open Cursor with STAF.Selenium.Tests folder
2. Press Cmd+K (Command Palette)
3. Type: "staf-page-action: Create a page and action for..."
4. Describe your screen and fields
5. Review and accept generated code
6. Run: dotnet test --filter "ClassName~YourClass"
```

**Reference:** `.cursor/skills/MASTER.md`
